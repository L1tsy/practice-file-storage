Файловое хранилище

1. Описать назначение системы

- какую задачу решает система?
	Система позволяет пользователю организовывать файловую структуру. 
- кто ей пользуется?
	Администратор, может видеть все файлы, и в случае ошибок - чинить и переносить файлы например. 
	Пользователи могут загружать файлы, разделять по папкам и т.д
- какие основные действия пользователь может выполнять
	Загружать, удалять, редактировать и искать файлы, создавать папки, давать им названия, пользователь видит только 	свои файлы, не имеет доступ к чужим 
	Сортировать по дате, названии, типу файла, и по размеру
- какие данные системе необходимо хранить
	Под каждого пользователя создать отдельную папку, и уже в этой папке будет хранилище пользователя, в бд 	присваивать владельца
	Скорее всего размер файла, название, тип файла и дату создания

2. Определить основные объекты системы
Определите, какие объекты существуют в вашей предметной области.

Пользователь
	- Хранить его login, имя, дату входа и выхода из/в систему, и дату создания, с какими обьектами он связан(С какой нибудь папкой или файлом)
Администратор
	- Хранить его login, дату входа и выхода из/в систему, иметь историю изменения(что изменяет администратор в системе)
Папка
	- Хранить дату создания, кол-во файлов в папке, размер папки, название, с какими обьектами он связан(С каким нибудь пользователем или файлом)
Файл
	- Хранить дату создания, размер, тип файла, название файла

4. Описать действия пользователя

Сценарий 1: 
Пользователь открывает систему, вводит логин и пароль.
Система проверяет вводимые данные.
Пользователь входит в систему, получает доступ к хранилищу.

Сценарий 2: 
Администратор открывает систему, вводит логин и пароль.
Система проверяет вводимые данные.
Администратор входит в систему, получает полный доступ ко всему хранилищу, открывает папку пользователя 1, удаляет 1 файл.
Система переносит удаленный файл в Корзину и записывает в список изменений что администратор удалил файл.
Администратор видит удаление файла.

5. Создать диаграмму одного сценария

Пользователь --> Система: Выполняет вход в систему
Система --> База данных: Проверяет данные
База данных --> Система: Отправляет результат проверки
Система --> Пользователь: Выдается доступ к хранилищу


6. Создать общую схему системы

User[Пользователь]
Admin[Администратор]
APP[Backend-сервис]
Data[База данных]

User -->|Запросы: папки, файлы, вход| APP
Admin -->|Администрирование и аудит| APP
    
APP -->|Чтение и запись метаданных| Data
Data -->|Результаты проверок и выборки| APP
    
APP -->|Данные хранилища| User
APP -->|Полный доступ и логи| Admin
